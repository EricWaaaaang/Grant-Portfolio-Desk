# Validation Grant Documents

These files are synthetic validation examples, not real funder records or Tidepath client data.

Each validation grant has a status-specific document set:

- Applying: 2 files per grant — application draft and proposed budget.
- Approved: 10 files per grant — proposal, award budget, spending, outcomes, progress, planning, funder and category controls, report template, and funder-year spend check.
- Completed: 11 files per grant — the completed record set plus a final settlement document.

Each status group contains five grants. Generated monthly plans, expenses, outcomes, and settlement references are mock values created only to exercise the app.
