# Sample grant proposals and spending records

This folder contains ten fictional grant proposals and ten matching monthly spending CSV files. They are synthetic challenge data for demonstrating and validating Tidepath workflows. They do not describe real organizations, awards, beneficiaries, or expenses.

Each `proposal-N-*.md` file is paired with the `proposal-N-*-monthly-budget-actuals.csv` file with the same grant number and project name. Values are illustrative and should not be represented as actual financial records.
